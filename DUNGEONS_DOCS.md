# Система подземелий - Документация

## Обзор

Полнофункциональная система подземелий с полной интеграцией боевой системы. Игроки могут исследовать подземелья, сражаться с врагами, получать награды и отслеживать свой прогресс.

### ✨ Новое: Интеграция с боевой системой

Когда игрок нажимает "Начать подземелье":
1. Система генерирует список врагов на основе данных подземелья
2. Враги имеют уровень и параметры, зависящие от сложности подземелья
3. Игрок переводится на боевой экран и сражается с врагами по очереди
4. Между боями HP и Мана восстанавливаются на 80%
5. При победе над всеми врагами выдаются награды и записывается прогресс
6. При поражении записывается неудачная попытка

## Структура данных (dungeons.json)

```json
{
  "id": "уникальный_id",
  "name": "Название подземелья",
  "difficulty": "L1|L2|L3",
  "difficultyColor": "#HEX цвет",
  "requiredLevel": число,
  "description": "Краткое описание",
  "image": "имя_файла.png",
  "enemies": ["Враг1", "Враг2", "Босс (босс)"],
  "rewards": [

    { "type": "item", "name": "Название", "rarity": "редкость", "chance": число },
    { "type": "experience", "value": число, "chance": число }
  ],
  "duration": "мин-макс мин",
  "description_full": "Полное описание",
  "tips": "Совет для игрока"
}
```

## Элементы интерфейса

### Вкладка подземелий

**Заголовок и статистика:**
- Название вкладки: "🏰 Подземелья"
- Статистика: количество пройденных подземелий, лучший результат

**Фильтры:**
- По сложности (L1, L2, L3)
- По статусу (Все, Не начато, Пройдено)

**Сетка карточек:**
- Каждая карточка показывает: название, сложность, описание, требуемый уровень
- Цветовая кодировка сложности (зеленый L1, оранжевый L2, красный L3)
- Статус прохождения (серый "не начато", желтый "в процессе", зеленый "пройдено")

### Детальная страница подземелья

При клике на карточку открывается:

**Вкладки информации:**
1. **Описание** - полное описание, требования, советы
2. **Враги** - список врагов и босса
3. **Награды** - таблица наград с шансами выпадения
4. **Прогресс** - история попыток прохождения

**Кнопка "Начать подземелье":**
- Активна если уровень игрока соответствует требованиям
- При нажатии сохраняет текущее состояние и переходит в режим подземелья

## Логика работы

### 1. Загрузка подземелий

```javascript
// Инициализация при открытии вкладки
DungeonsManager.init();
```

- Загружает данные из `dungeons.json`
- Проверяет требования уровня для каждого подземелья
- Отображает только доступные варианты

### 2. Фильтрация

```javascript
// Применяет текущие фильтры
applyFilters(dungeons)
```

**Критерии фильтрации:**
- Сложность (L1, L2, L3)
- Статус (все, не начато, пройдено)

### 3. Запуск подземелья

```javascript
// Начать подземелье
DungeonsManager.startDungeon(dungeonId)
```

**Проверки:**
1. Уровень игрока >= требуемый уровень
2. Сохранение текущего состояния игры
3. Инициализация прогресса подземелья
4. Переход в режим подземелья

### 4. Сохранение прогресса

```javascript
// Завершить подземелье
DungeonsManager.completeDungeon(dungeonId, success, score)
```

**Происходит:**
- Запись попытки (дата, статус, счет)
- Если успешно: добавляются награды, обновляется лучший результат
- Восстановление состояния игры (возврат в меню)

## Примеры подземелий

- **Уровень:** 1+
- **Враги:** Гоблины, волки, древний страж (босс)
- **Награды:** 500 золота, меч лесника (30%), 200 опыта

- **Уровень:** 5+

- **Награды:** 1000 золота, кристальный посох (20%), 500 опыта
- **Длительность:** 20-30 минут
- **Особенность:** Высокая магическая активность

### 3. Храм Тьмы (L3)

- **Уровень:** 10+
- **Враги:** Скелеты, призраки, вампиры, лич (босс)
- **Награды:** 2000 золота, меч Тьмы (10%), 1000 опыта
- **Длительность:** 40-60 минут
- **Особенность:** Самое опасное подземелье

### 4. Древняя библиотека (L2)

- **Длительность:** 25-35 минут

## Типичные ошибки и решения

### 1. Подземелья не загружаются

**Проблема:** Файл `dungeons.json` не найден или поврежден

**Решение:**
- Проверьте что файл находится в `/data/dungeons.json`
- Проверьте синтаксис JSON (используйте validator)
- Убедитесь что `dataLoader.loadDungeons()` вызывается

### 2. Фильтры не работают

**Проблема:** Выбранные фильтры не применяются

**Решение:**
- Проверьте что `applyFilters()` вызывается при изменении фильтра
- Убедитесь что значения в `select` совпадают с полями в JSON
- Проверьте консоль браузера на ошибки

### 3. Награды не добавляются

**Проблема:** После прохождения подземелья игрок не получает награды

**Решение:**
- Проверьте что `completeDungeon()` вызывается при завершении
- Убедитесь что метод `gameState.addGold()` существует
- Проверьте что шанс выпадения награды > 0

## Интеграция с боевой системой

Для полной интеграции с боевой системой:

1. Когда игрок запускает подземелье, вместо:
   ```javascript
   alert(`Начало подземелья: ${dungeon.name}`);
   ```

2. Сделать:
   ```javascript
   // Переход в режим боя/исследования подземелья
   BattleEngine.initiateDungeonBattle(dungeon, enemy);
   ```

3. При завершении боя:
   ```javascript
   DungeonsManager.completeDungeon(dungeonId, true, score);
   ```

## Методы DungeonsManager

### init()
Инициализирует систему подземелий, загружает данные и отрисовывает список

### renderDungeonsList()
Отрисовывает сетку карточек подземелий с применением фильтров

### showDungeonDetails(dungeonId)
Открывает детальное окно подземелья с вкладками

### startDungeon(dungeonId)
Запускает подземелье (проверяет требования, сохраняет состояние)

### completeDungeon(dungeonId, success, score)
Завершает подземелье (добавляет награды, сохраняет результат)

### applyFilters(dungeons)
Применяет текущие фильтры к списку подземелий

### updateStats()
Обновляет статистику на панели (количество пройденных, лучший результат)
