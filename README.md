# Narrative RPG - Рассказовая Ролевая Игра

Текстовая ролевая игра в браузере с уникальной боевой системой, множеством классов и локаций для исследования.

## 🚀 Быстрый Старт

### Требования
- Современный браузер с поддержкой ES6 модулей
- Локальный веб-сервер

### Установка и Запуск

**Через Python 3**
```bash
cd trp
python3 -m http.server 8000
# Откройте http://localhost:8000
```

**Через Node.js**
```bash
cd trp
npx http-server
```

**Через VS Code**
- Установите "Live Server"
- Кликните на `index.html` → "Open with Live Server"

## 🏗️ Архитектура

### Модули ES6

Проект построен на ES6 модулях для разделения логики:

```javascript
import { gameState } from './core/GameState.js';
import { DOMManager } from './core/DOMManager.js';
import { BattleEngine } from './battle/BattleEngine.js';
```

### Основные Компоненты

**GameState** - управление состоянием игры
**DOMManager** - работа с DOM элементами
**EventManager** - система событий приложения
**BattleEngine** - логика боевой системы
**ClassSelectionManager** - выбор класса персонажа
**LocationsManager** - управление локациями
**DataLoader** - загрузка JSON данных
**UIManager** - управление интерфейсом

## 📊 Игровые Данные

Все данные хранятся в JSON файлах в папке `data/`:

- **classes.json** - 6 классов персонажей с характеристиками
- **locations.json** - 3 локации с врагами и добычей
- **abilities.json** - пассивные способности

## 🎮 Ключевые Системы

### Боевая Система
- Пошаговый бой с случайными врагами
- Урон зависит от характеристик
- Анимированный интерфейс боя

### Выбор Класса
- 6 уникальных классов
- Выбор из 3 случайных способностей
- Влияние на HP, урон и другие параметры

### Локации для Исследования
- 3 локации с разным уровнем опасности
- Случайные враги в каждой
- Таблица возможной добычи

## 🔧 Развитие

### Добавить новый класс
1. Добавьте в `data/classes.json`
2. Он автоматически появится в меню выбора

### Добавить новую локацию
1. Добавьте в `data/locations.json`
2. Локация появится на вкладке "Мир"

### Добавить новую систему
1. Создайте новый модуль в `js/`
2. Импортируйте в `app.js`
