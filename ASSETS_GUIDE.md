# Руководство по структуре активов (изображений)

## Структура проекта

```
/workspaces/trp/assets/
├── img/
│   ├── background.jpg          ← Фоновое изображение для всех экранов
│   ├── фон.jpg                 ← Копия фона (старое имя)
│   └── enemies/                ← Папка для изображений врагов
│       ├── воришка.jpg
│       ├── стражник.jpg
│       ├── наёмник.jpg
│       ├── волк.jpg
│       ├── разбойник.jpg
│       └── тень.jpg
└── fonts/                      ← Папка для шрифтов
```

## Изображения врагов

### Структура папки
- **Путь:** `/assets/img/enemies/`
- **Формат:** JPG, PNG
- **Размер:** рекомендуется 200x200 пикселей или больше
- **DPI:** 72 DPI (для веба)

### Именование файлов

Имена файлов должны соответствовать значению `"image"` в файле `data/locations.json`.

#### Примеры из locations.json:

```json
{
  "enemies": [
    { "name": "Воришка", "image": "воришка.jpg", "hp": 20, "attack": 3 },
    { "name": "Волк", "image": "волк.jpg", "hp": 50, "attack": 8 }
  ]
}
```

## Добавление новых изображений врагов

1. **Подготовьте изображение:**
   - Размер: 200x200 пикселей или больше (квадратное)
   - Формат: JPG или PNG
   - Качество: оптимизировано для веба (~50-200 KB на изображение)

2. **Сохраните в правильную папку:**
   ```
   /assets/img/enemies/название.jpg
   ```

3. **Обновите data/locations.json:**
   ```json
   {
     "name": "Название врага",
     "image": "название.jpg",
     "hp": 50,
     "attack": 10
   }
   ```

4. **Развернитесь:**
   ```bash
   npm run deploy
   ```

## Требования к изображениям

### Техническое
- **Формат:** JPEG (стандартный для фотографий) или PNG (для графики с прозрачностью)
- **Размер файла:** 50-200 KB (оптимизировано)
- **Разрешение:** минимум 200x200 пикселей
- **Кодировка:** UTF-8 или ASCII для имён файлов (без кириллицы рекомендуется)

### Дизайн
- **Стиль:** соответствует общему стилю игры
- **Фон:** может быть прозрачным (PNG) или однородным (JPG)
- **Цветовая гамма:** согласуется с палитрой игры

## Пути в коде

### HTML
Изображение врага в боевом экране:
```html
<img id="enemyImage" src="" alt="враг">
```

### CSS
Стили для контейнера изображения находятся в `styles/components/battle.css`:
```css
.battle__enemy-image {
  width: 150px;
  height: 150px;
  /* ... */
}
```

### JavaScript
Загрузка изображения в `js/battle/BattleUI.js`:
```javascript
const enemyImage = DOMManager.getElementById('enemyImage');
if (enemyImage && enemy.image) {
  enemyImage.src = `/trp/assets/img/enemies/${enemy.image}`;
}
```

## Fallback изображение

Если изображение не загрузится, будет показана эмодзи 👹.

## Тестирование

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Network"
3. Начните бой
4. Проверьте, загружается ли изображение врага (должно быть "200 OK")
5. Если 404 - проверьте имя файла и путь
