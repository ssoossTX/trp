🚀 Как Запустить

Вариант 1: Python 3

cd trp python3 -m http.server 8000 # http://localhost:8000

Вариант 2: Node.js

cd trp npx http-server

Вариант 3: VS Code Live Server

Кликните правой кнопкой на index.html → "Open with Live Server"

🔑 Ключевые Модули

  • app.js - Точка входа, инициализирует всю игру
  • GameState.js - Управляет состоянием игрока и боя
  • DOMManager.js - Упрощает работу с DOM
  • EventManager.js - Система событий приложения
  • BattleEngine.js - Логика боевой системы
  • ClassSelectionManager.js - Выбор класса персонажа
  • LocationsManager.js - Управление локациями
  • DataLoader.js - Загрузка JSON данных
  • UIManager.js - Управление интерфейсом

📊 Полезная Информация

ES6 Модули

Приложение использует ES6 модули для разделения кода:

import { gameState } from './core/GameState.js'; import { BattleEngine } from './battle/BattleEngine.js'; import { dataLoader } from './data/DataLoader.js';

CSS Переменные

Единая система цветов и отступов через CSS переменные:

:root { --primary-color: #2c3e50; --accent-color: #e74c3c; --spacing-lg: 20px; }

BEM Методология

Классы именуются по принципу Block__Element--Modifier:

.card { } .card__header { } .card--active { }

✨ Преимущества Модульной Архитектуры

  • Разделение ответственности - каждый модуль отвечает за одно
  • Легкость расширения - новые функции добавляются просто
  • Переиспользуемость - модули применяются в других проектах
  • Читаемость - легче разобраться в коде
  • Масштабируемость - проект готов к росту
  • Тестируемость - каждый модуль тестируется отдельно
