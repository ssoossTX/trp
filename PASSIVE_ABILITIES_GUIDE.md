# Система пассивных способностей - Руководство и документация

## Обзор

Система пассивных способностей обеспечивает постоянные бонусы к различным игровым механикам. Каждая пассивная способность применяется на весь игровой сеанс и влияет на урон, защиту, здоровье, манупрофиль и получение опыта.

## Архитектура системы

### Основные компоненты

1. **abilities.json** - Определение всех пассивных способностей
2. **PassiveAbilityManager.js** - Класс управления эффектами пассивных способностей
3. **GameState.js** - Хранение текущей пассивной способности и применение эффектов
4. **BattleEngine.js** - Применение модификаторов урона и защиты в боевой системе
5. **UIManager.js** - Отображение информации о пассивной способности в профиле

### Структура данных пассивной способности

```javascript
{
  id: "усиленный_удар",                    // Уникальный идентификатор
  name: "Усиленный удар",                  // Название способности
  description: "Увеличивает наносимый урон на 10%",  // Описание
  type: "passive",                         // Тип (всегда "passive")
  icon: "⚔️",                              // Эмодзи иконка
  effects: {
    damageBuff: 0.10,                     // +10% урона
    hpBuff: 0,                            // Нет бонуса здоровья
    manaBuff: 0,                          // Нет бонуса маны
    defenceBuff: 0,                       // Нет защиты
    agilityBuff: 0,                       // Нет бонуса ловкости
    experienceBuff: 0                     // Нет бонуса опыта
  }
}
```

## Доступные пассивные способности

| Способность | Эффект | Бонус |
|------------|--------|-------|
| Усиленный удар | ⚔️ | +10% урона |
| Крепкое тело | ❤️ | +10% здоровья |
| Магический резерв | ✨ | +10% маны |
| Боевая хватка | ⚡ | +5 ловкости (плоская) |
| Древний артефакт | 🛡️ | -5% полученного урона |
| Боевой опыт | 📚 | +15% опыта |

## Интеграция с игровыми системами

### 1. Расчёт урона

**Где применяется:** Во всех случаях нанесения урона

```javascript
// В BattleEngine.playerAttack()
if (gameState.passiveAbility && gameState.passiveAbility.effects.damageBuff) {
  damage = Math.round(damage * (1 + gameState.passiveAbility.effects.damageBuff));
}

// В GameState методах активных способностей (activateShieldBash и т.д.)
if (this.passiveAbility && this.passiveAbility.effects.damageBuff) {
  damage = Math.round(damage * (1 + this.passiveAbility.effects.damageBuff));
}
```

**Примеры:**
- Обычная атака: 50 урона → с "Усиленный удар" → 55 урона
- Мощный удар (200% базового): 100 урона → с "Усиленный удар" → 110 урона

### 2. Защита от урона

**Где применяется:** Когда враг атакует игрока

```javascript
// В BattleEngine.enemyAttack()
if (gameState.passiveAbility && gameState.passiveAbility.effects.defenceBuff) {
  const defenceReduction = Math.round(damage * gameState.passiveAbility.effects.defenceBuff);
  damage = Math.max(1, damage - defenceReduction);
}
```

**Примеры:**
- Враг наносит 50 урона → с "Древний артефакт" → 47-48 урона (5% защиты)

### 3. Получение опыта

**Где применяется:** В методе GameState.addExperience()

```javascript
let finalAmount = amount;
if (this.passiveAbility && this.passiveAbility.effects.experienceBuff) {
  finalAmount = Math.round(amount * (1 + this.passiveAbility.effects.experienceBuff));
}
```

**Примеры:**
- Враг дает 100 опыта → с "Боевой опыт" → 115 опыта

### 4. Бонусы характеристик

**Где применяется:** При инициализации игрока

- **HP (Здоровье):** Увеличивает максимальное здоровье на процент
- **Mana (Мана):** Увеличивает максимальную ману на процент
- **Agility (Ловкость):** Добавляет плоский бонус к статистике ловкости

## API PassiveAbilityManager

### Методы

```javascript
// Применить пассивную способность
PassiveAbilityManager.applyPassiveAbility(ability)
// ability: { id, name, description, type, icon, effects }

// Убрать пассивную способность
PassiveAbilityManager.removePassiveAbility()

// Получить модификатор урона (множитель)
const modifier = PassiveAbilityManager.getDamageModifier()
// Возвращает: 1.0 (база), 1.1 (с +10%), 0.9 (с -10%) и т.д.

// Получить модификатор защиты (процент поглощённого урона)
const reduction = PassiveAbilityManager.getDefenceModifier()
// Возвращает: 0.0 (база), 0.05 (с -5%), 0.10 (с -10%) и т.д.

// Получить модификатор опыта (множитель)
const xpModifier = PassiveAbilityManager.getExperienceModifier()
// Возвращает: 1.0 (база), 1.15 (с +15%), 0.85 (с -15%) и т.д.

// Получить текстовое описание эффектов
const description = PassiveAbilityManager.getEffectsDescription()
// Возвращает строку с перечислением всех эффектов

// Проверить активна ли способность
const isActive = PassiveAbilityManager.isAbilityActive()
// Возвращает: true/false
```

## Примеры использования в коде

### Проверка активной способности

```javascript
if (gameState.passiveAbility) {
  console.log(`Активная способность: ${gameState.passiveAbility.name}`);
} else {
  console.log('Пассивная способность не выбрана');
}
```

### Получение эффекта

```javascript
const ability = gameState.passiveAbility;
if (ability && ability.effects.damageBuff) {
  const bonusPercent = ability.effects.damageBuff * 100;
  console.log(`Бонус урона: +${bonusPercent}%`);
}
```

### Удаление способности

```javascript
// Способность автоматически удаляется при смене класса
gameState.passiveAbility = null;
```

## Ограничения и особенности

1. **Одна способность на персонажа** - Одновременно может быть активна только одна пассивная способность
2. **Сохранение состояния** - Текущая активная способность сохраняется в gameState
3. **Применение эффектов** - Эффекты применяются при активации способности
4. **Перерасчет баз** - При переключении способностей автоматически перерассчитываются базовые значения

## Производительность

- **Память:** Каждая способность занимает ~300 байт
- **CPU:** Проверка эффектов занимает <1ms за проверку
- **Сетевые запросы:** Нет дополнительных запросов

## Возможные ошибки и решения

### Ошибка: Пассивная способность не отображается в профиле

**Решение:** Проверить что `updatePassiveAbilityDisplay()` вызывается в `updatePlayerProfile()`

### Ошибка: Эффекты не применяются к урону

**Решение:** Убедиться что проверка `gameState.passiveAbility` добавлена перед применением множителя

### Ошибка: Способность остаётся после смены класса

**Решение:** При смене класса вызвать `gameState.passiveAbility = null`
