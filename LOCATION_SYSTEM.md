# 🗺️ Система генерации локаций

## Описание
Полнофункциональная система для генерации, отображения и навигации по процедурно сгенерированным локациям в игре.

## Компоненты

### 1. **LocationGenerator.js** (`js/locations/LocationGenerator.js`)
Класс для генерации локаций с основной логикой игровой сетки.

**Основные возможности:**
- Генерация локации размером 90x90 квадратиков (3600x3600px)
- Каждый квадратик размером 40x40px
- Процедурная генерация противников (👹), деревьев (🌲) и камней (🪨)
- Игрок спавнится в центре (45, 45)
- Система коллизий - игрок не может пройти через объекты
- Система видимости - отображение видимой области вокруг игрока

**Основные методы:**
- `generateLocation()` - создает новую локацию
- `movePlayer(direction)` - перемещает игрока (возвращает true/false)
- `isValidMove(x, y)` - проверяет валидность движения
- `isCellOccupied(x, y)` - проверяет, занята ли клетка
- `getVisibleArea(width, height)` - получает видимую область
- `getLocationStats()` - получает статистику (количество врагов, деревьев, камней)
- `endLocation()` - завершает текущую локацию

### 2. **LocationUI.js** (`js/locations/LocationUI.js`)
Класс для управления пользовательским интерфейсом локации.

**Основные возможности:**
- Отображение сетчатой модели локации (10x10 квадратиков видимых)
- Камера следует за игроком
- Управление стрелками (вверх, вниз, влево, вправо)
- Поддержка клавиатурного управления (WASD или стрелки)
- Отображение статистики (враги, деревья, камни, позиция игрока)
- Кнопка выхода в главное меню

**Основные методы:**
- `init()` - инициализация UI
- `startTestLocation()` - запуск тестовой локации
- `openLocation()` - открыть экран локации
- `closeLocation()` - закрыть экран локации и вернуться в меню
- `render()` - отрисовка текущего состояния

### 3. **CSS Стили** (`styles/screens/location.css`)
Стили для экрана локации с гридом, управлением и адаптивным дизайном.

**Основные элементы:**
- `.location-screen__container` - контейнер экрана
- `.location-screen__viewport` - область отображения локации
- `.location-grid` - сетка локации
- `.location-cell` - отдельная клетка сетки
- `.controls-grid` - управление (стрелки)
- `.control-btn` - кнопки управления

## Интеграция

### В `index.html`
1. Добавлена ссылка на CSS:
   ```html
   <link rel="stylesheet" href="styles/screens/location.css">
   ```

2. Добавлена кнопка "🧪 Тест локации" в экран настроек:
   ```html
   <button class="test-location-btn" id="testLocationBtn">🧪 Тест локации</button>
   ```

### В `app.js`
1. Импортирован `locationUI`:
   ```javascript
   import { locationUI } from './locations/LocationUI.js';
   ```

2. Инициализирован в методе `init()`:
   ```javascript
   locationUI.init();
   ```

### В `UIManager.js`
1. Импортирован `locationUI`:
   ```javascript
   import { locationUI } from '../locations/LocationUI.js';
   ```

2. Добавлен слушатель для кнопки "Тест" в `initMenuNavigation()`:
   ```javascript
   const testLocationBtn = DOMManager.getElementById('testLocationBtn');
   if (testLocationBtn) {
     testLocationBtn.addEventListener('click', () => {
       this.hideAllScreens();
       locationUI.startTestLocation();
     });
   }
   ```

## Использование

### Запуск тестовой локации
1. Откройте игру
2. Перейдите в главное меню
3. Нажмите на "⚙️ Настройки"
4. Нажмите на кнопку "🧪 Тест локации"
5. Вы увидите сгенерированную локацию с сеткой 10x10 видимых клеток

### Управление
- **Стрелки вверх/вниз/влево/вправо** или **WASD** - движение по локации
- **Кнопки со стрелками в UI** - альтернативное управление
- **ESC** - выход в главное меню
- **Кнопка "Выход"** - выход в главное меню

## Особенности

### Генерация объектов
- **Враги (👹)**: ~4% от общего количества клеток (макс 15)
- **Деревья (🌲)**: ~3.5% от общего количества клеток (макс 25)
- **Камни (🪨)**: ~2.5% от общего количества клеток (макс 20)
- Ни один объект не может спавниться на клетке с игроком
- Два объекта не могут спавниться на одной клетке

### Видимость
- Игрок видит 10x10 клеток вокруг себя
- Камера автоматически центрируется на игроке
- При подходе к краю карты окно "прилипает" к границе

### Эмодзи обозначения
- 🧙 - игрок
- 👹 - враг/противник
- 🌲 - дерево
- 🪨 - камень
